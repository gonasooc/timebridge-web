- 최근 갱신: 2026-10-02
- 관련 문서: [docs/README.md](../README.md), [AGENTS.md](../../AGENTS.md), [README.md](../../README.md), [docs/work/W-002-main-coaching-mvp.md](W-002-main-coaching-mvp.md)

## 현재 상황

사용자가 기존 결과물의 폐기를 예정하고 기존 배포 문서 삭제와 관련 자료 정리를 요청했다. 이 작업에서는 배포 문서·참조·옛 앱 출시 지침을 제거하고 문서 연결과 당시 제품 코드 보존을 확인했다. 이후 옛 앱 화면·자산 제거와 기술·디자인 설명 갱신은 [docs/work/W-002-main-coaching-mvp.md](W-002-main-coaching-mvp.md)의 내부 시안 구현에서 수행했다.

- 완료 조건: 불필요한 배포 문서·링크·옛 앱 출시 고정 규칙이 제거되고, 유효한 MVP 기획과 작업 기록이 유지되며 다음 정리 범위가 명시될 것.
- 사람이 판단할 사항: 없음. 기존 화면의 기술·디자인 설명 갱신은 MVP 구현 작업에서 수행.

## 진행과 판단

### 배경과 범위

문서 구조 초기화 때는 기존 자료 보존이 요구되어 배포 문서와 정책 문안 고정 규칙을 유지했다. 이후 사용자가 이전 결과물과 불필요한 문서의 폐기를 허용했으므로 해당 규칙을 새 MVP에 승계하지 않도록 정리한다. 이번 작업은 문서와 에이전트 지침을 대상으로 한다.

### 중요한 시도와 결정

- 2026-10-02 — `docs/`와 루트 README·에이전트 지침을 검토했다. 별도 삭제 대상은 `docs/deploy_remaining_tasks.md`이며, 옛 앱의 스토어 제출·외부 앱 약관 동기화·정책 문안 고정 메모는 README와 AGENTS 등에 남아 있었다.
- 2026-10-02 — 배포 문서를 삭제하고 [README.md](../../README.md), [AGENTS.md](../../AGENTS.md), [docs/plan.md](../plan.md), [docs/specs.md](../specs.md)에서 새 상품과 무관한 고정 절차를 제거했다. Context7 지침과 docs-starter 공통 규칙은 유지했다.
- 2026-10-02 — 초기 코칭 기획인 [docs/mvp-plan.md](../mvp-plan.md), docs-starter 작업 기록, 기술·디자인 문서는 계속 유효하므로 유지했다. 기존 코드에 관한 설명은 현재 상태를 나타내며 MVP 구현 후 실제 변경과 함께 정리한다.
- 2026-10-02 — W-001의 당시 보존·검증 기록은 유지하고 삭제 문서의 링크만 일반 경로와 후속 작업 링크로 바꿨다. 기록 당시 결과를 이번 작업의 검증 결과로 바꾸지 않았다.

### 검증

- 삭제 대상과 관련 참조 검색 — 확인. 저장소의 Markdown 문서와 에이전트 지침을 검토했다.
- 문서 상대경로 검사 — 통과. Markdown 14개의 링크 대상 존재를 확인했고 삭제 문서로 연결되는 링크는 없다.
- 폐기 지침 검색 — 통과. 배포 문서 경로는 삭제·보존 당시의 작업 기록에만 일반 텍스트로 남아 있다. 앱 출시 고정 규칙의 유효한 참조는 제거했다.
- 기존 비문서 파일 SHA-256 비교 — 통과. 제품 코드·설정·공개 자산 등 21개 기존 파일의 내용이 동일하다.
- 에이전트 공통 규칙과 양식 비교 — 통과. docs-starter 공통 지침과 작업·세션 양식, CLAUDE 연결을 유지했다. Context7 블록도 유지했다.
- `git diff --check` — 통과. 공백 오류 없음.
- 제품 코드·빌드 — 이번 작업에서 변경·실행하지 않음. 문서 정리의 검증으로 제품 테스트를 반복하지 않는다.
