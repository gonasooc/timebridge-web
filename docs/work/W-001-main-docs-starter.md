- 관련 문서: [docs/README.md](../README.md), [docs/plan.md](../plan.md), [docs/architecture.md](../architecture.md), [docs/specs.md](../specs.md), [docs/design.md](../design.md)

## 현재 상황

로컬 docs-starter의 한국어 문서 구조를 적용하고 코드·설정과 기존 기획을 대조해 초기 문서를 작성했다. 기존 문서와 이전 세션의 미커밋 변경을 유지했으며 문서 연결·원문 보존·빌드 검증을 마쳤다. 다음 제품 구현은 예정 작업 W-002에서 시작한다.

- 완료 조건: 문서 홈·제품·구조·기술·디자인 문서와 작업·세션 양식이 연결되고, 기존 자료·에이전트 지침이 보존되며 미정 사항이 구분되어 있을 것.
- 사람이 판단할 사항: 이번 문서 구조 적용에는 없음. 제품·배포의 미정 사항은 담당 문서에서 관리.

## 진행과 판단

### 배경과 범위

사용자는 먼저 docs-starter의 한국어 구조 적용을 요청했다. 웹 화면 구현 대신 현재 코드에 근거한 문서 초기화를 수행한다. 원본 템플릿은 형제 저장소의 docs-starter에서 읽고 대상 프로젝트에 필요한 정보를 채웠다.

### 중요한 시도와 결정

- 2026-10-02 — 시작 시 `main` 브랜치에 이전 세션의 `README.md` 수정과 미추적 `docs/mvp-plan.md`가 있었다. 기존 파일의 내용 해시를 기록한 뒤 원문 보존을 비교하기로 했다.
- 2026-10-02 — 현재 웹은 HTML 네 페이지이며 코칭 기능은 계획 단계임을 확인했다. [docs/plan.md](../plan.md)는 현재 구현과 사용자 합의를 구분하고, [docs/architecture.md](../architecture.md)와 [docs/specs.md](../specs.md)는 실제 코드·설정을 근거로 작성했다.
- 2026-10-02 — 루트 에이전트 파일은 없었다. [AGENTS.md](../../AGENTS.md)에 템플릿 공통 규칙과 세션에서 전달받은 Context7 지침·README의 정책 문안 보존 규칙을 합치고, [CLAUDE.md](../../CLAUDE.md)는 공통 규칙을 참조하도록 했다.
- 2026-10-02 — 문서 초기화 당시 `docs/mvp-plan.md`와 `docs/deploy_remaining_tasks.md`를 변경 없이 보존했다. 다음 MVP 작업은 [docs/work/W-002-main-coaching-mvp.md](W-002-main-coaching-mvp.md)에 예정으로 등록했다. 이후 사용자 요청에 따른 배포 문서 삭제와 관련 지침 정리는 [docs/work/W-003-main-obsolete-docs.md](W-003-main-obsolete-docs.md)에 기록했다.
- 2026-10-02 — [docs/design.md](../design.md)는 소스에서 관찰한 패턴과 기존 README 기준을 구분했다. 브라우저에서 확인하지 않은 시각적 결과는 미확인으로 남겼다.

### 검증

- 코드·설정 읽기 — 확인. `package.json`, 잠금 파일, 빌드 설정, 공용 JS·CSS·HTML과 공개 자산을 대조했다.
- 현재 로컬 환경 — Node.js `v20.19.0`, pnpm `10.33.1`. `.nvmrc` 지정값은 `22.13.1`로 로컬 실행값과 다름.
- 문서 상대경로 검사 — 통과. 루트 지침·README와 `docs/`의 Markdown 14개에서 링크 대상 존재를 확인했다.
- 기존 파일 SHA-256 비교 — 통과. README와 `.gitignore`의 의도한 추가를 제외한 기존 문서·코드·설정은 동일하다. 두 파일도 추가한 내용 외 원문 보존을 확인했다.
- 템플릿·지침 비교 — 통과. 템플릿 AGENTS 규칙을 그대로 포함하고 프로젝트 지침을 추가했다. CLAUDE 연결과 작업·세션 양식은 원본과 동일하다.
- `git diff --check` — 통과. 변경 내용의 공백 오류 없음.
- `git check-ignore docs/.local/example.md Thumbs.db` — 통과. 개인 메모와 추가 OS 메타데이터 제외를 확인했다.
- `pnpm build` — 통과. macOS, Node.js `v20.19.0`, pnpm `10.33.1`에서 HTML 네 페이지와 CSS·JS 산출물을 생성했다. 브라우저 렌더링과 운영 배포 검증은 포함하지 않는다.
- 브라우저 화면·운영 배포·AI 전사 — 미실행. 이번 문서 적용으로 검증되지 않음.
