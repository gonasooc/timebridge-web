# W-002 코칭 MVP 화면과 신청 흐름 구현

- 상태: 진행 중
- 최근 갱신: 2026-10-02
- 관련 문서: [docs/README.md](../README.md), [docs/plan.md](../plan.md), [docs/architecture.md](../architecture.md), [docs/specs.md](../specs.md), [docs/design.md](../design.md), [docs/mvp-plan.md](../mvp-plan.md)

## 현재 상황

가상 인물의 샘플과 네 화면의 내부 시안을 구현하고, Dribbble 레퍼런스와 사용자 요청에 따라 종이색·자주색 유지 및 Pretendard 통일 리디자인을 완료했다. 모바일·데스크톱 화면과 기존 기능을 검증했다. 실제 신청은 전송·저장하지 않으며, 이후 상담 저장·운영자 확인·회신 경로를 연결한다. 호스팅·결제·AI 전사 도구는 미정이다.

- 완료 조건: 모바일에서 소개·방향 선택·가상 샘플·상담 신청 흐름을 조작하고, 실제 저장된 시험 신청을 운영자가 확인할 수 있을 것. 모집 공개와 유료 운영 준비는 별도로 확인.
- 사람이 판단할 사항: 첫 화면·문항 검토, 상담 저장·회신 수단, 호스팅, 결제 수단, AI 전사 도구와 자료 처리 방식. 첫 시안 완료를 전체 MVP 완료로 표시하지 않는다.

## 진행과 판단

### 배경과 범위

합의한 상품 범위와 데이터 정책은 [docs/plan.md](../plan.md)를 따른다. 초기 상세 제안은 [docs/mvp-plan.md](../mvp-plan.md)를 참고한다. 이번 구현은 첫 단계인 내부 시안이며 실제 접수 연결은 별도 단계다.

### 중요한 시도와 결정

- 2026-10-02 — 사용자가 색감 유지와 함께 Dribbble 세 레퍼런스를 활용한 시각 개선을 요청했다. 이어서 전체 서체를 Pretendard로 지정해 제목·본문·인용·폼을 통일했다. 기울어진 종이를 정렬된 가상 기록으로 바꾸고 둥근 패널·컨트롤·단계 표시와 얇은 경계선으로 위계를 정리했다. 기능·상품 범위·연락처 처리 방식은 유지했다. 레퍼런스 확인 범위는 [docs/design.md](../design.md)에 기록했다.
- 2026-10-02 — 문서 구조 초기화와 함께 다음 구현 작업으로 등록했다. 기존 무료 가족 앱 화면과 코칭 상품의 차이를 확인하고 실행 순서를 정리했다.
- 2026-10-02 — 사용자가 이전 결과물과 불필요한 문서의 폐기를 허용했다. 기존 앱 배포 문서와 관련 고정 규칙을 정리했다. 근거는 [docs/work/W-003-main-obsolete-docs.md](W-003-main-obsolete-docs.md)에 있다.
- 2026-10-02 — [index.html](../../index.html)을 소개·선택·샘플·상담 초안의 네 화면으로 교체했다. [src/main.js](../../src/main.js)에 해시 이동·선택 유지·입력 검증·초안 확인을 구현했다. 부모님 앱 설치나 별도 프레임워크 도입을 선행하지 않았다.
- 2026-10-02 — [src/sample-data.js](../../src/sample-data.js)에 가상 인물 이정희와 세 주제의 질문·대화·피드백을 구성했다. 대상·연대·주제·걱정을 진행 안내에 반영하되 전사 예시는 고정 가상 인물임을 명시했다.
- 2026-10-02 — 연락처는 DOM의 초안에만 표시한다. 방향 선택의 허용된 열거 값만 세션 저장하고, 상담 폼은 기본 제출 차단·dialog 방식·비활성 초기 제출 버튼으로 전송을 막았다. 연락처는 새로고침·문서 이탈 시 지우며 초안 문자열은 HTML로 해석하지 않는다.
- 2026-10-02 — [src/coaching.css](../../src/coaching.css)에 종이색·자주색, 고운바탕 제목·Pretendard 입력, 모바일 한 열, 키보드 초점과 오류 상태를 구현했다. [PRODUCT.md](../../PRODUCT.md)와 [DESIGN.md](../../DESIGN.md)는 제품 맥락과 정본 문서 연결점이다.
- 2026-10-02 — 옛 무료 앱의 정책·지원 세 HTML, 전용 아이콘·브랜드·정책 링크 partial, PNG 아이콘·공유 이미지를 제거했다. 빌드에는 index 하나만 남겼다. 실제 처리 방식이 정해지기 전 이전 정책을 코칭 정책처럼 제공하지 않는다. `noindex`·`robots.txt`는 시안의 색인 억제이며 접근 통제가 아니다.
- 2026-10-02 — 별도 코드 검토에서 본문 건너뛰기가 홈 화면으로 이동하는 문제를 발견했다. 현재 화면을 유지하면서 main으로 포커스를 옮기도록 수정했다. 회귀 검사를 브라우저 테스트에 추가해 통과했다.
- 2026-10-02 — 한국어 문서 구조와 Context7 지침을 유지하면서 현재 코드에 맞춰 README·제품·구조·기술·디자인 문서를 갱신했다. 이전 작업 문서의 당시 검증 기록은 보존했다.

### 검증

- 환경 — macOS, Node.js `v20.19.0`, pnpm `10.33.1`, Playwright `1.63.0`. `.nvmrc` 지정은 `22.13.1`로 현재 실행값과 다르다.
- `node --check src/main.js`, 가상 샘플 모듈 문법·필드 구조 검사 — 통과.
- `pnpm build` — 통과. 옛 페이지 제거 뒤 HTML 하나와 CSS·JS를 생성했다.
- `pnpm test:e2e` 첫 실행 — 데스크톱 Chromium·Pixel 7 Chromium 에뮬레이션 16개 통과. 전체 흐름·누락·주제 변경·뒤로 가기·새로고침·직접 주소 진입·이메일 검증·초안 escaping·연락처 비전송 및 비저장·가로 넘침·키보드 초점을 확인했다.
- `pnpm test:e2e` 최종 실행 — 22개 모두 통과(6.2초). 본문 건너뛰기의 현재 단계 유지·본문 초점, 320px·768px 네 화면의 가로 넘침, 모션 감소 시 애니메이션 비활성, 다크 선호에서도 밝은 코칭 테마 유지까지 확인했다.
- 브라우저 화면 — 데스크톱과 Pixel 7 에뮬레이션의 네 화면을 캡처했다. 홈·선택·샘플·상담의 레이아웃과 글꼴·CTA·가상 표시를 직접 확인했다. 외부 폰트 로딩 완료를 확인했다. 스크린샷은 `/private/tmp/timebridge-preview/`의 임시 검토 산출물이며 저장소에 포함하지 않는다.
- 읽기 전용 코드 검토 — 본문 건너뛰기 수정 외 추가 중대 문제를 발견하지 못함. 동작 검증과 구분한다.
- 문서·산출물 — Markdown 16개 상대 링크와 `git diff --check` 통과. 빌드 산출물은 index·CSS·JS·SVG 아이콘·robots이며 옛 정책 페이지와 PNG는 포함하지 않는다.
- 로컬 미리보기 — `http://127.0.0.1:4173/` 개발 서버에서 HTTP 200 응답 확인. 서버 재실행 명령은 `pnpm dev --host 127.0.0.1 --port 4173 --strictPort`다. 공개 배포가 아니다.
- 실제 접수 저장·운영자 조회·회신·결제·AI 전사·배포 — 미실행·미구현. 실물 휴대폰·Safari·스크린리더 전수 점검도 미실행.

### 리디자인 검증

- `pnpm build` — 통과. 전체 폰트에서 Google Fonts·고운바탕을 제거하고 기존 Pretendard 스택을 사용한다.
- `pnpm test:e2e` — 데스크톱·Pixel 7 Chromium 기존 22개 모두 통과(3.3초). 입력·초안·전송 차단·선택 유지와 320/768px 네 화면의 가로 넘침·모션 감소·테마를 확인했다.
- 화면 캡처 — 데스크톱·모바일 네 화면, 상담 초안, 홈 viewport 총 12장 확인. 한글과 주요 행동·선택값·가상 예시 표시의 잘림 없음. 폰트 로딩 완료 및 body·h1의 Pretendard 적용, 브라우저 console error·pageerror 0 확인.
- 스크롤한 상태의 전체 화면 캡처에서 비활성 skip-link가 보이는 현상을 확인해 포커스가 없을 때 명시적으로 숨겼다. 키보드 접근은 유지하고 관련 테스트 2개를 다시 통과했다. 샘플 설명을 버튼으로 오인할 수 있는 장식 화살표도 제거했다.
- 캡처는 `/private/tmp/timebridge-modern-preview/`, 확인한 레퍼런스 이미지는 `/private/tmp/timebridge-modern-refs/`의 임시 산출물이며 저장소에 포함하지 않는다.
- 검증 범위는 Chromium과 모바일 에뮬레이션이며 Safari·실물 휴대폰·운영 배포는 미실행이다.
