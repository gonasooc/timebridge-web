# 제품 기획

현재 구현과 합의한 제품 방향을 구분한다. 코드 확인 기준일은 2026-10-02이며, 코칭 MVP에 관한 결정 근거는 보존한 [docs/mvp-plan.md](mvp-plan.md)다. 개별 구현 순서와 상태는 [docs/work/W-002-main-coaching-mvp.md](work/W-002-main-coaching-mvp.md)에서 관리한다.

## 목적과 사용자

현재 구현은 [index.html](../index.html)의 부모님 인터뷰 코칭 내부 시안이다. 소개·방향 선택·가상 샘플·상담 내용 미리보기를 제공하며 실제 신청은 받지 않는다. 이전 무료 가족 앱의 소개·정책·지원 화면은 제거했다.

합의한 코칭 MVP는 부모님의 이야기를 남기고 싶지만 인터뷰를 혼자 준비하고 진행하기 부담스러운 성인 자녀를 돕는다. 자녀가 인터뷰하고 운영자가 준비와 피드백을 제공한다. 부모님의 앱 설치나 계정 생성을 참여 조건으로 두지 않는다.

## 이번 범위

| 구분 | 범위와 확인 기준 |
| --- | --- |
| 현재 구현 | 소개 → 방향 선택 → 가상 샘플 → 상담 내용 미리보기. 실제 접수 전 단계 |
| 합의한 MVP | 서비스 소개 → 인터뷰 방향 선택 → 가상 인물 기반 맞춤 샘플 → 상담 신청 |
| 운영 목표 | 커뮤니티·SNS를 통해 유료 5가구를 모집하고 운영자가 8주 코칭을 직접 제공 |
| 기본 상품 | 베타 가격 9.9만원, 상담 3회, 맞춤 질문 40개, 인터뷰 2회, 총 2시간의 검수된 전사본 |
| 기본 결과물 | 말한 순서를 유지하고 화자를 구분한 기록. 사람이 전사 오류를 확인하고 불명확한 부분을 표시 |
| 후속 상품 | 주제별 재구성·윤문과 책 제작. 기본 코칭에 책은 포함하지 않음 |
| 이번 구현의 제외 범위 | 자체 채팅, 회원가입, 고객 대시보드, 녹음 업로드, 책 편집기를 초기 구현의 필수 기능으로 두지 않음 |

실제 저장된 상담 신청과 확인된 결제를 구분한다. 베타에서는 5가구 중 4가구 이상이 가구별 시작일부터 8주 안에 인터뷰 2회를 완료하는지 확인하고, 고객당 실제 작업 시간을 기록한다. 이는 목표이며 현재 실적이 아니다.

## 핵심 기능과 사용자 흐름

현재 방문자는 소개와 FAQ를 읽고 대상·출생 연대·관심 주제를 선택한다. 샘플에서 질문·두 번의 인터뷰 목표와 가상 전사·피드백을 살펴본 뒤, 상담 폼에 가상의 이름·이메일·시작 시기·대화 방식·부모님 참여 의향을 입력해 초안을 확인한다. 입력 내용은 전송·저장되지 않고 새로고침 시 비워진다.

코칭 MVP에서는 연락처 입력 전에 인터뷰 방향과 샘플을 확인하도록 한다. 고객 선택에 따라 질문과 인터뷰 목표가 달라지며, 전사본은 가상 인물의 서비스 이용 예시로 보여준다. 이후 상담에서 부모님의 참여 의향, 일정, 코칭 방식에 대한 기대를 확인하고 상품과 결제를 안내한다.

시안의 필수 선택은 대상(어머니·아버지), 출생 연대, 관심 주제다. 걱정은 선택 항목이다. 출생 연대와 관심 주제에는 ‘잘 모르겠어요’를 제공한다. 주제는 어린 시절·일과 선택·나를 키우던 시절이며, 가상 인물 이정희 한 명의 일관된 예시를 사용한다. 상담 폼의 시기·대화 방식에는 미정 선택지를 둔다. 문항·필수 여부는 시안 검토 후 공개 버전에 맞춰 조정할 수 있다.

## 제품 정책과 제약

- 공개 샘플은 가상 인물의 더미 데이터로 만든다. 실제 고객 사례나 전사 정확도·완주율의 근거로 소개하지 않는다.
- 당사자 동의와 보안 조건 확인을 전제로 AI 전사를 허용하며 사람이 검수한다. AI 요약·해석·원고화까지 허용한 것으로 확대하지 않는다.
- 초기 상담과 결제 확인은 기존 수단으로 운영한다. 구체적인 수단은 미정이다.
- 코칭용 정책은 실제 상담 정보와 녹음의 처리·보관·삭제 방식에 맞춰 작성한다. 기존 앱용 정책의 기능·업체·조건을 그대로 적용하지 않는다.
- 사용자 요청에 따라 이전 결과물은 교체 대상이며 옛 앱 배포 절차와 정책 문안 고정 규칙은 폐기했다. 근거는 [docs/work/W-003-main-obsolete-docs.md](work/W-003-main-obsolete-docs.md)에 있다.
